# Changelog

## 0.2.1

- The Commit tool window is back in the bottom panel; no Activity Bar icon.
- Clicking the branch in the status bar opens the Git tool window instead of the Git Branches popup.

## 0.2.0

- Changes view: selecting a file (mouse or `↑`/`↓`) previews its diff and keeps focus in the tree.
- Previous / Next Changed File in the diff editor title step through the changes in tree order.
- The Commit tool window moved from the bottom panel to the Activity Bar on the left, so diffs get the full editor area.

## 0.1.0

- Git tool window with the Log: branches and tags tree, commit graph with labels, filters, commit details and context menus for branches, tags and commits.
- Commit tool window: changes tree with checkboxes, Merge Conflicts / Changes / Unversioned Files, group by directory, diff on click, multi-file diff.
- Commit Message view: Commit, Commit and Push…, Amend, message history, prefilled merge messages.
- Rollback, Add to VCS, Add to .gitignore, Delete for unversioned files.
- Git Branches popup in the status bar with all branch actions and Smart Checkout.
- Fetch, Update Project (merge or rebase with autostash), Push dialog with outgoing commits, force push with lease and rejected-push handling.
- Conflicts dialog (Merge…, Accept Yours, Accept Theirs), Continue / Skip / Abort for merge, rebase, cherry-pick and revert.
- Tags: Tags section in the Log and the Branches popup, New Tag…, Push Tags, Push Tag and Delete Tag.
- Commit and Git tabs in the bottom panel, no Activity Bar icon.
- JetBrains file status colors in the Explorer, editor tabs, the Changes view and the Log (`git-awesome.jetbrainsColors`).
- Resizable and hideable Log columns, resizable panes.
- Optional JetBrains keymap.
